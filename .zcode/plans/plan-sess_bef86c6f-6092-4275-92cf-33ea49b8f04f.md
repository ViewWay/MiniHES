# 单表每日数据展示设计方案

## 核心思路

将 daily 分析页面从"单日概览"改为**分层展示**，用 Tabs 切换不同维度，每个 Tab 充分利用 MongoDB 中的真实 DLMS 采集数据。

## 页面结构

```
筛选栏：项目 → 设备 → 日期范围
    ↓
Tab 切换： [概览] [三相数据] [负荷曲线] [计费数据] [事件日志]
    ↓
每个 Tab 内容区
```

---

## Tab 1: 概览（当前 daily 页面增强）

保留现有统计卡片 + 每日趋势图，增加更多汇总字段：

**统计卡片（4→6 个）：**
- 采集天数、累计电能、日均增量、最新总有功功率、平均功率因数、数据完整率

**趋势图（2→3 个）：**
- 每日用电增量柱状图（现有）
- 累计电能趋势折线图（现有）
- 三相功率分布图（新增：L1/L2/L3 每日功率变化）

**明细表增强列：**
```
日期 | 累计电能 | 日增量 | L1电压 | L2电压 | L3电压 | L1电流 | L2电流 | L3电流 | 有功功率 | 无功功率 | 完整率 | 状态
```

---

## Tab 2: 三相数据

展示最新一次采集的三相瞬时量详情：

**三相不平衡度卡片：**
- 电压不平衡度：`max(|Vab-Vavg|, ...) / Vavg * 100%`
- 电流不平衡度

**三相对比柱状图：**
- L1/L2/L3 电压、电流、有功功率、无功功率并列对比

**瞬时量明细表：**
```
项目 | L1 | L2 | L3 | 总计
电压(V) | 233 | 232 | 234 | -
电流(A) | 1 | 9 | 0 | -
有功功率(W) | 13 | 32 | 107 | 458
无功功率(var) | 8 | 3 | 0 | 12
视在功率(VA) | - | - | - | 193
功率因数 | 计算 | 计算 | 计算 | 计算
```

---

## Tab 3: 负荷曲线（Load Profile 96 点）

展示最新采集的 **96 点负荷曲线**（15 分钟间隔）：

**图表：**
- 24 小时负荷曲线（X 轴 00:00~23:45 每 15 分钟一个点，Y 轴功率/电能）
- 峰谷平时段标注（不同背景色区分峰/平/谷时段）

**统计卡片：**
- 峰值功率、谷值功率、平均功率、峰谷差、峰谷比

---

## Tab 4: 计费数据（Daily/Monthly Billing）

**日计费趋势图（365 天）：**
- X 轴日期，Y 轴每日电量，可看到长期用电规律
- 标注月度结算点

**月计费柱状图（12 月）：**
- 12 个月每月用电量对比

**费率分布饼图：**
- rate1 / rate2 / 反向 比例

---

## Tab 5: 事件日志

**事件时间线：**
- 标准事件、欺诈检测事件、电能质量事件、通信事件
- 按时间倒序排列
- 事件类型用 Tag 颜色区分（critical=红, warning=橙, info=蓝）

## 后端改动

### `analysis_mongo_service.py` 的 `daily_analysis` 方法增强

返回数据增加：
```python
{
  # 现有字段保留
  "daily_records": [...],  # 增加 L2/L3 电压电流

  # 新增：最新一次采集的三相详细数据
  "phase_data": {
    "voltage": {"l1": 233, "l2": 232, "l3": 234},
    "current": {"l1": 1, "l2": 9, "l3": 0},
    "active_power": {"l1": 13, "l2": 32, "l3": 107, "total": 458},
    "reactive_power": {"l1": 8, "l2": 3, "l3": 0, "total": 12},
    "apparent_power": {"total": 193},
    "power_factor": {"l1": 0.85, "l2": 0.99, "l3": 0, "total": 0.94},
  },

  # 新增：96 点负荷曲线
  "load_profile": {
    "labels": ["00:00", "00:15", ..., "23:45"],  # 96 个
    "values": [0.5, 0.3, ...],  # 每点功率
  },

  # 新增：计费数据
  "billing": {
    "daily": {"labels": [...], "values": [...]},  # 365 天
    "monthly": {"labels": [...], "values": [...]},  # 12 月
    "rates": {"rate1": 209885, "rate2": 0, "export": 0},
  },

  # 新增：事件
  "events": [{"name": "...", "time": "...", "severity": "..."}],
}
```

### `MongoSessionRepo` 新增方法

- `get_load_profile_96(meter_id)` → 解析 Load Profile buffer 为 96 点
- `get_billing_data(meter_id)` → 解析 Daily/Monthly Billing buffer
- `get_phase_data(meter_id)` → 提取三相瞬时量
