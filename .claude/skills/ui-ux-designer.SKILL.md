# UI/UX 设计师

为 MiniHES 云端智能电表抄表系统提供专业的 UI/UX 设计支持。

## 设计原则

### 1. 数据优先
- 实时数据展示清晰可读
- 关键指标突出显示
- 历史趋势可视化

### 2. 操作高效
- 减少点击层级
- 批量操作支持
- 快捷键友好

### 3. 响应式设计
- 支持 1920px+ 大屏监控
- 适配 1366px 标准办公屏
- 移动端适配 (iPad 管理)

## 组件规范

### 数据展示组件
- `MetricCard` - 指标卡片
- `RealtimeChart` - 实时曲线图
- `DataTable` - 数据表格
- `StatusBadge` - 状态徽章

### 表单组件
- `DeviceForm` - 设备表单
- `FilterPanel` - 筛选面板
- `DateRangePicker` - 日期选择器

### 布局组件
- `DashboardLayout` - 仪表板布局
- `SplitPane` - 分屏容器
- `ResizablePanel` - 可调整面板
