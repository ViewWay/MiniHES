本项目使用 **frontend-patterns** skill 确保前端开发遵循最佳实践。

## MiniHES 前端技术栈

### 框架与库
- **Nuxt 3** - Vue 3 全栈框架
- **TypeScript** - 类型安全
- **Pinia** - 状态管理
- **VueUse** - 组合式工具集

### 样式方案
- **Tailwind CSS** - 原子化 CSS
- **Nuxt UI** - UI 组件库
- **CSS Modules** - 组件隔离样式

### 数据获取
- **$fetch** - 原生数据请求
- **useAsyncData** - 服务端数据获取
- **useLazyFetch** - 懒加载

### 开发规范
- 使用 Composition API
- 组件命名: PascalCase
- 文件命名: kebab-case.vue
- 组合式函数: use*.ts
