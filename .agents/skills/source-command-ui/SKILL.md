# source-command-ui

Use this skill when the user asks to run the migrated source command `ui`.

## Command Template

使用 frontend-design skill 为 MiniHES 设计界面。

## 设计流程

1. **需求分析** - 理解功能需求
2. **页面结构** - 定义布局和组件
3. **交互设计** - 设计用户流程
4. **视觉实现** - 编写高质量 UI 代码

## 使用方法

```
/ui 设计设备管理页面
/ui 设计实时监控面板
/ui 设计数据报表
```
